# ZPTech Homepage Hero Concept

A responsive, premium homepage concept built with:

- HTML5 semantic structure
- Bootstrap 5.3
- Custom CSS
- jQuery 3.7
- Native HTML5 background video
- Responsive image fallbacks
- Reduced-motion accessibility support
- Scroll reveal and navigation behavior

## Hero video

The demo uses a remotely hosted Coverr MP4 as a live placeholder. The final production hero should be a real, licensed 15–20 second 16:9 MP4 encoded specifically for web delivery.

Recommended production export:

- 1920×1080 maximum desktop master
- H.264 MP4
- 24/25/30 fps
- No audio track
- Target roughly 3–6 Mbps, depending on motion/detail
- Keep the final file as short as possible while retaining visual quality
- Add a compressed poster image for the first paint and mobile fallback

## Creative direction

The hero deliberately avoids product shots. The intended final footage should combine real people, natural landscapes, active movement and quiet moments, with restrained lighting that can sit between modern laboratory/science imagery and meditation/wellness imagery.

For production, use real stock footage or original photography/video rather than AI-generated footage if the brand requirement is that the result must not look AI-generated.

## Local production video

Replace the `<source>` URL in `index.html` with:

`assets/video/zptech-hero.mp4`

This lets the final hero load from your own CDN/server and gives you full control over caching, compression and licensing.
